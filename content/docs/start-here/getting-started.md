Doks is a documentation template for the [Thulite web framework](https://thulite.io/), built for speed, security, and SEO, and powered by Hugo and npm. It helps you build production-ready documentation sites with exceptional performance, enterprise-grade security, scalable architecture, and a developer-friendly workflow.

## Prerequisites

- [Hugo](https://github.com/gohugoio/hugo/releases/latest) (latest extended or extended/deploy edition)
- [Thulite](https://github.com/thuliteio/thulite/releases/latest) (latest version)
- [Node.js/npm](https://nodejs.org/en/download) (latest LTS version)
