Doks is a modern documentation theme for [Thulite](https://thulite.io), built for clarity, speed, and ease of use. It helps you create readable, user-friendly documentation sites with features like search, code highlighting, internationalization, and versioning.

## Prerequisites

- [Hugo](https://github.com/gohugoio/hugo/releases/latest) (latest extended or extended/deploy edition)
- [Node.js/npm](https://nodejs.org/en/download) (latest LTS version)
